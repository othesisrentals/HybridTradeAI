## ?? Getting Started

### Quick Start (Development)

```bash
# 1. Clone and install
git clone <repo-url>
cd hybridtradeai
npm install

# 2. Set up environment
cp .env.example .env
# Edit .env with your credentials

# 3. Set up database
npm run db:push
npx ts-node --compiler-options {\"module\":\"CommonJS\"} prisma/seed.ts

# 4. Start development server
npm run dev
```
