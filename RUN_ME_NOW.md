## ? STEP 1: Find the ` key on your keyboard

Look at your keyboard and find this key:


It has two symbols: **~** (tilde) and **`** (backtick)

It's usually in the top-left corner, next to the number **1** key.

---

## ? STEP 2: Press Ctrl + `

**Press both keys at the same time:**
- Hold down **Ctrl** (bottom-left of keyboard)
- While holding Ctrl, press **`** (the key from Step 1)

**A dark box will appear at the bottom of Cursor!**

This is called the **TERMINAL**.

---

## ? STEP 3: Type this command

In that dark box (terminal), **carefully type** this:

```
npm run dev
```

**OR** right-click and paste if you copied it.

Then press **Enter** on your keyboard.

---

## ? STEP 4: Wait for "Ready"

You'll see text scrolling. **This is normal!**

Wait until you see something like:

```

Local: http://localhost:3000
```

**DO NOT CLOSE THE TERMINAL!** Leave it running.

---

## ? STEP 5: Open your browser

**Open Google Chrome, Microsoft Edge, or Firefox.**

---

## ? STEP 6: Type this in the address bar

At the top of your browser where you type websites, type:

## ?? TROUBLESHOOTING

### Problem: "Can't find the ` key"
**Solution:** Look for the key with **~** and **`** symbols. It's in the top-left area, usually next to **Esc** and **1**.

### Problem: "Terminal won't open"
**Solution:** Try this instead:
1. Click **"View"** at the top of Cursor
2. Click **"Terminal"**
3. Click **"New Terminal"**

### Problem: "Command gives an error"
**Solution:** First run this command:
```
npm install
```
Wait for it to finish (30-60 seconds), then try:
```
npm run dev
```

### Problem: "Browser says can't connect"
**Solution:** 
- Make sure the terminal is still running (don't close it!)
- Wait until you see "Ready" in the terminal
- Try typing: **http://localhost:3000** (with http://)
